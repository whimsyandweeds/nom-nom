# Nom Nom Pet Pantry

A single-page website for Nom Nom Pet Pantry — a community pet pantry in Las Vegas helping pets stay fed and stay home.

Pro-bono showcase built with care by Whimsy & Weeds.

## Features
- Responsive hero with looping plaid paw-print video background (desktop & mobile versions)
- How to Help (Amazon Wishlist + GoFundMe)
- Most Needed (kitten food)
- Meet the Pets gallery
- Donation photos
- Book a Pickup (Google Calendar)
- Embedded Pantry Questionnaire
- Brand collabs contact
- Erica’s story timeline
- Contact links

## Local preview
Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8080
```
